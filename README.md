## 📋 Descripción
Esta es la landing page pública oficial de **Águila Inventario Pro**, desplegada en Netlify. Presenta las ventajas clave de la plataforma:
* ⚡ **Modo Ferrari**: Recepción de mercancía con 0ms de latencia perceptible.
* 🏢 **Selector de Bodegas Inteligente**: Despliegue exclusivo de bodegas con existencias reales (`cajas > 0`).
* 📅 **Control de Caducidades FEFO**: Desacople inteligente de alertas en productos agotados.
* 📈 **Promedio Diario con 1 Decimal**: Cálculo matemático de venta diaria para reabastecimiento exacto.
* 📷 **Escáner Óptico Google ML Kit**: Lectura ultra-rápida de códigos de barras.
* 📶 **Soporte 100% Offline**: PWA preparada para operar en bodegas sin cobertura celular.

---

## 🛠️ Tecnologías
* **HTML5 Semántico** y **CSS3 Moderno** (variables CSS, Flexbox, CSS Grid).
* **Fuentes e Iconos**: Google Fonts (`Manrope`) y Google Material Icons Round.
* **Hosting**: Netlify CI/CD con despliegue automático desde GitHub.
* **PWA Manifest**: Configuración para instalación directa desde el navegador.
